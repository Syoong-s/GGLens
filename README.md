# FQ GGLens

FQ GGLens measures the excess surface density (ESD) of galaxy groups from DESI Legacy Imaging Surveys DR9 group catalogs and Fourier Quad shear catalogs. Choose the brightest central galaxy (BCG), the luminosity-weighted center (LWC), or the number-weighted center (NWC) for each run.

A run saves the measured ESD and its uncertainties, the best-fit profile, the range of fitted profiles, and a figure. The tables contain the values needed to plot the results again.
